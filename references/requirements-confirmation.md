# Requirements confirmation

Before writing the project overview, confirm only the decisions that affect boundaries:

- target users;
- deployment model;
- data location for data-intensive systems;
- model location and input types for AI systems;
- entities, user flow, roles, and permissions for business systems.

After confirmation, offer two or three architecture/technology/scope options with trade-offs. Let the user choose before promoting the overview and technology decisions to `D2`.

The overview must include positioning, boundaries, key decisions, non-goals, and unresolved assumptions.
