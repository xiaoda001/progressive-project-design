# Vertical-slice planning

Use this before a slice starts. A slice is the smallest runnable end-to-end loop across the necessary modules and one primary data flow.

Record in the roadmap:

- slice name and goal;
- modules involved;
- user-observable or operational result;
- dependencies and preferred implementation order;
- completion condition;
- link to the verification/backtest cases;
- planned evidence and slice directory.

Only modules involved in the current slice receive L1 documentation. Promote technology choices to `D2` and involved modules to `D2`/`D3` only after the relevant decisions are confirmed.

Do not create a future slice directory before its roadmap registration.
